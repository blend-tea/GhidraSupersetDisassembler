# v0.1.0 — AMACE Superset Disassembly for Ghidra 12.2

**English** | [日本語](https://github.com/blend-tea/GhidraSupersetDisassembler/blob/main/docs/releases/v0.1.0_ja.md)

Initial release for **Ghidra 12.2**. Requires **Java 25**.

## Features

- Fixed 32-bit and 64-bit x86 support for ELF, PE, and Raw Binary.
- Exhaustive instruction decoding at every byte offset, retaining overlapping candidates.
- AMACE-based backward analysis of stack depth, pointer definedness, and callee-saved registers, plus non-returning-call inference.
- Conservative automatic application of instructions and functions to the Listing; unresolved overlaps are deferred.
- GUI candidate table, headless script, and JSONL reports.
- Rollback on cancellation, Undo/Redo, and preservation of existing definitions and user metadata.
- Fix for competing modal dialogs during GUI execution: Ghidra's analysis manager now owns the single progress/cancellation window.

## Installation

Download `ghidra_12.2_PUBLIC_20261111_GhidraAmace.zip`, add it through **File → Install Extensions**, and restart Ghidra. Enable `AmacePlugin`, decline standard Auto Analyze after import, then use **Tools → AMACE → Analyze and Apply**.

`GhidraAmace-source.zip` contains build and test sources. Use `SHA256SUMS` to verify the attached ZIPs.

## Validation

Passed: 45 engine checks, 41 selection checks, abstract-domain regressions, six Ghidra integration fixtures (ELF/PE/Raw × 32/64-bit), 84 real-SLEIGH assertions, packaged CLI/JSONL validation, and GUI smoke checks. Actual 4,096-instruction GUI runs also verified normal completion, cancellation, reentry protection, and a single modal window.

See [validation details](https://github.com/blend-tea/GhidraSupersetDisassembler/blob/main/docs/VALIDATION.md).

## Known limitations

All candidates and P-code are retained in memory. Large inputs can exhaust the Java heap. Restrict the scope or adjust heap limits according to available RAM. Large-corpus accuracy/performance evaluation has not been performed. Unsupported P-code effects remain unknown.

## References

This is an independent Java/P-code implementation. Function-entry candidate generation and Listing selection use extension-specific policies.
