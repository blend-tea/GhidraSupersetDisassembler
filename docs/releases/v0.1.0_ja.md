# v0.1.0 — AMACE Superset Disassembly for Ghidra 12.2

[English](v0.1.0.md) | **日本語**

Ghidra 12.2向けの初回リリースです。Java 25が必要です。

### 機能
- x86 32/64bitのELF、PE、Raw Binaryに対応。
- 全バイト位置から命令候補をデコードし、重複する候補も保持。
- AMACEに基づくスタック深度・ポインタ定義条件・保存レジスタの後方解析と非復帰呼出し推定。
- 確度を優先して命令・関数をListingへ自動反映。競合候補は保留。
- GUI候補一覧、headlessスクリプト、JSONLレポート。
- GUI実行時のモーダル画面の二重起動を修正。画面が開閉を繰り返す原因を除去し、進捗・キャンセル画面をGhidra側の1つに統一。
- キャンセル時のロールバック、Undo/Redo、既存の定義・ユーザーメタデータの保持。

### インストール
`ghidra_12.2_PUBLIC_20261111_GhidraAmace.zip`をダウンロードし、GhidraのFile → Install Extensionsから追加して再起動します。AmacePluginを有効にし、標準のAuto Analyzeを開始する前にTools → AMACE → Analyze and Applyを実行してください。

`GhidraAmace-source.zip`はビルド・テスト用ソース一式です。`SHA256SUMS`で各ZIPのチェックサムを確認できます。

### 検証
解析エンジン45項目、命令選別41項目、抽象ドメインの回帰テスト、ELF/PE/Raw × 32/64bitの6種類のGhidra結合テスト、実SLEIGHの84項目、配布CLI/JSONLとGUI構築のsmoke検証が成功しています。4096命令のGUI実解析でも通常終了・キャンセルとモーダル画面が1回だけ開くことを検証しています。詳細はリポジトリのdocs/VALIDATION_ja.mdを参照してください。

### 既知の制約
全候補とP-codeをメモリに保持するため、大規模入力でJava heap space不足が起こり得ます。範囲を限定するかRAMに合わせてヒープ上限を調整してください。大規模コーパスでの精度・性能評価は未実施です。未対応P-codeはunknownとして保持します。
